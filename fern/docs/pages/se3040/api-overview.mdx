## Base URL

- **Published docs (this assignment):** [https://sustain-site-api.docs.buildwithfern.com/](https://sustain-site-api.docs.buildwithfern.com/)
- **Local API:** `http://localhost:5000`
- **Production API:** set by your deployment (e.g. Render) — details under **Deployment report** in the sidebar.

Most REST routes live under `/api`. JWT is sent as `Authorization: Bearer <token>` unless the route is public (e.g. register/login).

## Authentication

All protected endpoints require JWT authentication:

```bash
# Include token in Authorization header
curl -X GET http://localhost:5000/api/projects \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```

### User Roles

| Role | Description |
|------|-------------|
| ADMIN | Full system access |
| PROJECT_MANAGER | Manage projects and resources |
| INSPECTOR | Update sustainability metrics, conduct inspections |
| SUPPLIER | Update material delivery status |
| VIEWER | Read-only access |

## Route prefixes (Express)

| Area | Base path | Notes |
|------|-----------|--------|
| Health | `GET /health` | Liveness / platform checks |
| API index | `GET /api` | JSON index of major route groups |
| Auth | `/api/auth` | Register, login, profile, password |
| Projects | `/api/projects` | CRUD, milestones, timeline, financial summary |
| Sustainability | `/api/sustainability` | Metrics, scores, trends |
| Documents | `/api/documents` | Upload, versioning, approval workflow |
| Compliance | `/api/compliance` | Checklists, inspections, project score |
| Safety | `/api/safety` | Aggregated safety / high-risk inspections |
| Materials | `/api/materials` | Material inventory |
| Equipment | `/api/equipment` | Equipment management |
| Suppliers | `/api/suppliers` | Supplier management |
| Users (admin) | `/api/users` | Role-guarded user management |

### 2. Authentication (/api/auth)

#### POST /api/auth/register

Register a new user.

- **Auth Required:** No
- **Request Body:**
```json
{
  "fullName": "John Doe",
  "email": "john@example.com",
  "password": "Password123",
  "role": "VIEWER"
}
```

```bash
curl -X POST http://localhost:5000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"fullName":"John Doe","email":"john@example.com","password":"Password123","role":"VIEWER"}'
```

**Response (201):**
```json
{"success": true, "message": "Registration successful", "user": {...}, "token": "eyJ..."}
```

#### POST /api/auth/login

Login and receive JWT token.

- **Auth Required:** No
- **Request Body:**
```json
{"email": "john@example.com", "password": "Password123"}
```

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"john@example.com","password":"Password123"}'
```

**Response (200):**
```json
{"success": true, "message": "Login successful", "token": "eyJ...", "user": {...}}
```

#### GET /api/auth/me

Get current user profile.

- **Auth Required:** Yes
- **Roles:** All

```bash
curl -X GET http://localhost:5000/api/auth/me \
  -H "Authorization: Bearer <token>"
```

**Response (200):**
```json
{"user": {"_id": "...", "fullName": "John Doe", "email": "john@example.com", "role": "VIEWER"}}
```

#### PATCH /api/auth/profile

Update profile.

- **Auth Required:** Yes
- **Request Body:**
```json
{"fullName": "John Smith", "jobTitle": "Engineer"}
```

```bash
curl -X PATCH http://localhost:5000/api/auth/profile \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"fullName":"John Smith","jobTitle":"Engineer"}'
```

#### PATCH /api/auth/change-password

Change password.

- **Auth Required:** Yes
- **Request Body:**
```json
{"currentPassword": "OldPass123", "newPassword": "NewPass123"}
```

```bash
curl -X PATCH http://localhost:5000/api/auth/change-password \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"currentPassword":"OldPass123","newPassword":"NewPass123"}'
```

### 3. Projects (/api/projects)

#### POST /api/projects

Create a new project.

- **Auth Required:** Yes
- **Roles:** ADMIN, PROJECT_MANAGER
- **Request Body:**
```json
{
  "projectName": "Downtown Office Complex",
  "description": "A 20-story office building",
  "location": {"address": "123 Main Street", "latitude": 6.9271, "longitude": 79.8612},
  "startDate": "2026-06-01",
  "endDate": "2027-12-31",
  "budget": 50000000,
  "status": "Planning"
}
```

```bash
curl -X POST http://localhost:5000/api/projects \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"projectName":"Downtown Office Complex","description":"A 20-story office building","location":{"address":"123 Main Street","latitude":6.9271,"longitude":79.8612},"startDate":"2026-06-01","endDate":"2027-12-31","budget":50000000,"status":"Planning"}'
```

**Response (201):**
```json
{"success": true, "message": "Project created", "project": {...}}
```

#### GET /api/projects

List all projects (paginated).

- **Auth Required:** Yes
- **Roles:** ADMIN, PROJECT_MANAGER, INSPECTOR, VIEWER
- **Query Params:** `page`, `limit`, `status`, `search`

```bash
curl -X GET "http://localhost:5000/api/projects?page=1&limit=10" \
  -H "Authorization: Bearer <token>"
```

**Response (200):**
```json
{"projects": [...], "pagination": {"page": 1, "limit": 10, "total": 5, "pages": 1}}
```

#### GET /api/projects/:id

Get project by ID.

- **Auth Required:** Yes
- **Roles:** Project Members

```bash
curl -X GET http://localhost:5000/api/projects/607e5f3a2b8c4d3a1b4e3d2c1 \
  -H "Authorization: Bearer <token>"
```

#### PUT /api/projects/:id

Update project.

- **Auth Required:** Yes

### 5. Documents (/api/documents)

#### POST /api/documents

Upload document.

- **Auth Required:** Yes
- **Roles:** ADMIN, PROJECT_MANAGER, INSPECTOR
- **Content-Type:** multipart/form-data

```bash
curl -X POST http://localhost:5000/api/documents \
  -H "Authorization: Bearer <token>" \
  -F "file=@blueprint.pdf" \
  -F "projectId=607e5f3a2b8c4d3a1b4e3d2c1" \
  -F "title=Building Blueprint v1" \
  -F "documentType=Blueprint"
```

**Response (201):**
```json
{"success": true, "document": {"title": "Building Blueprint v1", "status": "Draft", "fileUrl": "...", "version": 1}}
```
