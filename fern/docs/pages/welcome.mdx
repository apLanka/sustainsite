## Local preview

From the repository root (with [Fern CLI](https://buildwithfern.com/learn/cli-api-reference/cli-reference/overview) installed):

```bash
cd fern && npx fern-api@0.56.12 docs dev
```

## Regenerate API spec for Fern

After adding or changing routes, update `apps/backend/src/config/openapi.paths.ts`, then:

```bash
npm run docs:export-openapi
```

This updates `fern/openapi/openapi.json`. Commit the result so Fern CI/build stays in sync.

## Publish (Fern Cloud)

```bash
cd fern
npx fern-api@0.56.12 login              # once per machine
npx fern-api@0.56.12 generate --docs    # or --no-prompt in CI with FERN_TOKEN
```

Update `fern.config.json` **organization** and `docs.yml` **instances[0].url** to match your Fern dashboard org.
